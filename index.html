制作 #001

今日の仕事整理ツール

頭の中にあるタスクを書き出すだけで、「今日やる」「5分でできそう」「後回しでもOK」の3つに整理できる、シンプルなWebアプリです。

制作した理由

仕事や副業をしていると、やることが色々あるはずなのに、頭の中がごちゃごちゃして何から手をつければいいか分からない瞬間があります。その状態を、紙に書き出すような感覚でパッと整理できたら少しラクになるのではないか、という思いから制作しました。

コンセプト

今日の仕事を、少し整理。
手作業を、少しラクに。

今日の仕事整理ツール

今日の仕事を、少し整理。

頭の中にあることを、そのまま書いてください。

🌤

今日やる（最大3件）

    ⏱

    5分でできそう

      🌙

      後回しでもOK

        手作業を、少しラクに。

        主な機能

        • タスクをまとめて入力できる入力欄
        • 「整理する」で3カテゴリに自動振り分け（今日やる／5分でできそう／後回しでもOK）
        • 完了チェック（取り消し線＋薄い表示）
        • 「今日の内容をリセット」（確認してから削除）
        • 「サンプルを試す」ですぐに動作を確認
        • 入力内容・整理結果・チェック状態をブラウザ内に保存

        使用技術

        HTML / CSS / JavaScriptのみで構成し、フレームワークは使用していません。外部AIサービスやAPIキーも使用せず、判定はすべてブラウザ内のシンプルなルールで行っています。データはブラウザの localStorage にのみ保存され、外部サーバーへの送信は一切ありません。

        今後改善したいこと

        • 現在はキーワードと文字数によるルールベースの分類のため、将来的にはAIを活用した文脈判定にも発展させたい
        • カテゴリやキーワードをカスタマイズできる機能
        • 完了したタスクを日ごとに振り返れる履歴表示
        • ダークモードへの対応
